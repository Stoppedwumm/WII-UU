WII-UU Support Downloads

Install, update, or free disk space

Open the installer

On macOS and Linux, run the web installer from a terminal.

curl -fsSL https://wiiuu.stoppedwumm.net/get.sh | bash

On Windows, download and extract the release ZIP, then run install.bat.

Setting up a dedicated Linux console? See the OEM setup walkthrough.

When WII-UU is already installed, the installer offers Uninstall, Repair, Update, and Optimize device space. The macOS and Linux web installer opens the menu before downloading the full package. Repair uses the files in the installer you opened, and Update checks the release server.

If the drive ran out of space

  1. If extraction is still asking whether to continue, press Ctrl+C to stop it.
  2. Run the installer again and choose Optimize device space. Review the preview before confirming deletion. Close WII-UU and any other installers first.
  3. Try the update again after freeing space. The updater still needs room to download and extract the package.

Optimize skips staging folders modified in the last 24 hours. If WII-UU cannot start, use the standalone cleanup JAR with Java 17 or newer. The first command previews eligible files. The second removes them.

java -jar WII-UU-Cleanup.jar
java -jar WII-UU-Cleanup.jar --apply

Download WII-UU-Cleanup.jar

Test a GitHub Actions build

  1. Open a successful build and download the WII-UU artifact. Choose the artifact ZIP listed under the workflow run.
  2. In WII-UU, open Settings → System → Choose a build ZIP, then select Install selected beta build.
  3. After WII-UU restarts, reopen the GamePad page so the phone loads the updated controls.
