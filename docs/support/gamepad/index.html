Connect and troubleshoot the GamePad

Pair your phone

  1. Start WII-UU and press + to show the pairing card.
  2. Connect your phone and computer to the same network. Scan the QR code or open the address shown on the TV.
  3. Enter the pairing code if prompted.

If the local address does not open, check whether the computer’s firewall allows WII-UU’s GamePad port, which defaults to 8080.

Use the relay on restricted Wi-Fi

If the network isolates devices, open Settings → GamePad & players → Start internet relay and scan the relay QR code. The relay needs internet access on both devices. Share the QR code and pairing code only with the people joining your session.

Refresh an installed GamePad web app

Restart WII-UU on the computer after an update, then reopen the GamePad. Recent builds check the page version and reload automatically after they connect. If the installed web app keeps opening a page from before automatic refresh was added, open the current pairing URL in your browser and re-add the app from there.

Check capture and input on macOS

Launch WII-UU.app and check its permissions in System Settings → Privacy & Security. Screen recording permission is used for desktop capture, and Accessibility is used for keyboard input. If WII-UU reports that a helper failed to build, check capture-build.log or pads-build.log in the WII-UU data folder’s logs directory.
