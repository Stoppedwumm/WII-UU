WII-UU UI Library

Use the same game screen renderer, display filters, and button types that WII-UU and Choccy Milk share. Version 1.1.0 also includes theme scripting, menu palettes, Cocoa/Milk painting and icons, and a reusable intro animation. The standalone JAR works with Java 17 or newer and uses Java desktop APIs. Emulation, the GamePad server, and the WII-UU launcher are separate applications.

  • Download the official 1.1.0 release
  • Browse the Java API reference
  • Download the renderer example
  • Download the theme and animation example

Run the example

Put UiDemo.java and WII-UU-UI-1.1.0.jar in the same folder. Compile the example with a JDK, then run it.

javac -cp WII-UU-UI-1.1.0.jar UiDemo.java
java -cp "WII-UU-UI-1.1.0.jar:." UiDemo

On Windows, use the following launch command.

java -cp "WII-UU-UI-1.1.0.jar;." UiDemo

Render your own frames

  1. Create a wiiuu.engine.GameScreen and call look to choose a filter and optional widescreen stretch.
  2. Pass packed 0xRRGGBB pixels to frame in row order, with the width, height, and display aspect ratio. Use aspect 0 to derive it from the dimensions. Keep submitted arrays unchanged if frame blending is enabled.
  3. Call paint from your Swing component’s paintComponent method. Request a repaint after delivering each frame.

Use pictureBounds to map input through letterboxing, announce to draw a temporary notification, and GameScreen.key to translate common keys to wiiuu.input.PadButton. SystemTheme.isDark() queries the desktop theme. Call it off the Swing event thread if you need to keep the UI responsive.

Themes and animation

wiiuu.ui.MenuPalette.colours(dark) returns an independent map of WII-UU’s menu colours. Evaluate a .wtheme string with MenuPalette.evaluate(source, fallbackName, systemDark). Its result includes colours, font preferences, warnings and dark-mode metadata. Apps with console tiles can use ThemeScript.evaluate with their own palette and console-colour providers. Loading files and applying the resulting colours belong to the host app.

MilkTheme.COCOA and MilkTheme.MILK expose Choccy Milk’s colours, background, selection pills, shadows, glass artwork and window icons. MilkTheme.pick(setting, systemDark) supports auto, cocoa/dark and milk/light.

MilkTheme look = MilkTheme.COCOA;
MilkIntro intro = new MilkIntro(look, "My app", "Welcome");
// In paintComponent, using the same millisecond clock:
long now = System.currentTimeMillis();
look.paintPage(g, getWidth(), getHeight(), 80, 1, now);
intro.paint(g, getWidth(), getHeight(), now);

The host owns repaint scheduling and skip input. done(now) reports completion after 3.5 seconds; cover(now) reports fade opacity. The explicit-start constructor supports deterministic snapshots. The intro preserves the caller’s graphics state; other painting methods use the supplied context, so use a copy from Graphics2D.create().

Compile ThemeDemo.java against the same JAR as above, then run ThemeDemo. For a headless preview, append --snapshot themes.png.
