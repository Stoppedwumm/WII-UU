WII-UU UI Library

Use the same game screen renderer, display filters, and button types that WII-UU and Choccy Milk share. The standalone JAR works with Java 17 or newer and uses Java desktop APIs. Emulation, the GamePad server, and the WII-UU launcher are separate applications.

  • Download the official 1.0.0 release
  • Browse the Java API reference
  • Download the Swing example

Run the example

Put UiDemo.java and WII-UU-UI-1.0.0.jar in the same folder. Compile the example with a JDK, then run it.

javac -cp WII-UU-UI-1.0.0.jar UiDemo.java
java -cp "WII-UU-UI-1.0.0.jar:." UiDemo

On Windows, use the following launch command.

java -cp "WII-UU-UI-1.0.0.jar;." UiDemo

Render your own frames

  1. Create a wiiuu.engine.GameScreen and call look to choose a filter and optional widescreen stretch.
  2. Pass packed 0xRRGGBB pixels to frame in row order, with the width, height, and display aspect ratio. Use aspect 0 to derive it from the dimensions. Keep submitted arrays unchanged if frame blending is enabled.
  3. Call paint from your Swing component’s paintComponent method. Request a repaint after delivering each frame.

Use pictureBounds to map input through letterboxing, announce to draw a temporary notification, and GameScreen.key to translate common keys to wiiuu.input.PadButton. SystemTheme.isDark() queries the desktop theme. Call it off the Swing event thread if you need to keep the UI responsive.
