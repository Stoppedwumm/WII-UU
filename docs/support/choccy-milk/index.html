Set up Choccy Milk and Nintendo DS

Choose a core

Open Settings → Games → Choccy Milk cores in WII-UU, or Settings → Cores in standalone Choccy Milk. Choose a core for the console, download or reinstall it, or select Automatic. Core changes apply the next time you launch a game.

Put the lower DS screen on your phone

  1. Enable Split DS screens in Choccy Milk under Settings → Games.
  2. Launch a DS game with Choccy Milk. The computer’s WII-UU window shows the upper screen.
  3. On the phone’s Now playing screen, select Show touch screen. Tap the lower screen to use the DS stylus.

Use or edit the Mario Kart DS layout

On the GamePad, choose Controls → Mario Kart DS or leave it on Automatic. Steer with the left thumb and hold Forward with the right. Slide up to drift or down to use an item. Both gestures keep acceleration held.

Use the switch below the screen to return to standard controls. To create your own layout, open Now playing → Edit layouts. Custom layouts are saved in the browser or installed web app on that phone.

Report a slowdown

Race the same track once with the GamePad stream closed and once with the lower screen streaming. Include a [choccy] speed: line from logs/nds.log for each run, along with your WII-UU version, operating system, and selected core. The logs are inside your WII-UU data folder.
