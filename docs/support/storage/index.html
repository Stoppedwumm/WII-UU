WII-UU Support Downloads

Move data to a drive or another computer

Move data to another drive

  1. Close games and other WII-UU apps. Open Settings → System → Storage and migration → Move to another drive.
  2. Choose a parent folder on the new drive, then enter a name for a folder that does not exist yet.
  3. Wait for Data is ready, then quit and reopen WII-UU. Verify your games and saves before removing the original files.

The app copies WII-UU data and the standard ROM library. Custom ROM folders stay in their original locations. The ~/.wiiuu-location file tells WII-UU and its installers where to find data and stage updates. Keep the selected drive connected when you start WII-UU.

If the destination looks empty

During a copy, WII-UU writes to a hidden .wiiuu-transfer-* folder in the selected parent folder. The final folder gets its name when the copy completes. In Finder, press Command+Shift+. to show hidden files. Check the staging folder’s size twice, about a minute apart, to see whether it is growing.

Transfer to another computer

  1. Connect both computers to the same local network and close any running games.
  2. On computer A, select Send to another computer and choose its address on that network.
  3. On computer B, select Receive from another computer, paste the migration code, and choose a new destination folder.
  4. When computer B reports Data is ready, restart WII-UU there. Set up any custom ROM folders and pair with other WII-UUs again.

External emulator installations and saves stored in those emulators’ own folders need to be moved separately. The receiving computer can download its own Choccy Milk cores and relay helper as needed.
