A browser home for WII-UU

Choccy Milk’s browser host and the Gambatte Game Boy core run in WebAssembly. The shared UI library has a Canvas port, including all desktop picture filters.

This is a web preview, not the complete desktop application. DS and other systems, phone pairing, online play, OEM setup, desktop integrations and idle cutscenes are not included yet.

No ROMs are uploaded. Milk Run is an original included homebrew game. Gambatte is GPL-2.0 licensed; its pinned source and build instructions are linked below.
