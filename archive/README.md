# WII-UU archive service

Dependency-free Node.js 20+ service (22+ recommended). Listens on **127.0.0.1:8081** by default, ready for a Cloudflare Tunnel. No reverse proxy, TLS server, npm dependencies or database installation is required.

## Google Cloud VM setup (Ubuntu/Debian)

Install Node.js 22 if it is not already installed:

```bash
sudo apt-get update
sudo apt-get install -y git curl
curl -fsSL https://deb.nodesource.com/setup_22.x -o /tmp/nodesource_setup.sh
sudo bash /tmp/nodesource_setup.sh
sudo apt-get install -y nodejs
node --version
```

Clone the implementation branch until PR #37 has merged:

```bash
git clone --branch codex/extract-shared-ui-components --single-branch https://github.com/Stoppedwumm/WII-UU.git
cd WII-UU
sudo bash archive/install.sh
curl http://127.0.0.1:8081/healthz
```

The installer creates a `wiiuu-archive` systemd service, generates an upload token once, and preserves configuration and release files on subsequent runs. Releases live in `/var/lib/wiiuu-archive`; back up that directory and `/etc/wiiuu-archive.env`. Put the data directory on a persistent Google Cloud disk if you replace the VM.

In Cloudflare Tunnel add a public hostname:

- Hostname: `wii-uu-archive.stoppedwumm.net`
- Service type: HTTP
- URL: `127.0.0.1:8081`

The public origin is configured in `/etc/wiiuu-archive.env`; generated download links use it. If cloudflared runs in Docker, use host networking or set `HOST` to a reachable interface explicitly.

```bash
sudo systemctl status wiiuu-archive --no-pager
sudo journalctl -u wiiuu-archive -n 50 --no-pager
```

The archive initially has no releases: `/healthz` works immediately; version feeds return 404 until a release of that channel is published.

## Enable GitHub Actions uploads

Print the upload token on your VM:

```bash
sudo sed -n 's/^ARCHIVE_TOKEN=//p' /etc/wiiuu-archive.env
```

In the WII-UU repository's **Settings → Secrets and variables → Actions** add:

| Kind | Name | Value |
| --- | --- | --- |
| Repository variable | `WIIUU_ARCHIVE_URL` | `https://wii-uu-archive.stoppedwumm.net` |
| Repository secret | `WIIUU_ARCHIVE_TOKEN` | The token printed on your VM |

Set these after the tunnel is reachable. Default-branch beta builds and explicit version tags will upload to the archive before publishing their GitHub release. The uploaded update manifest points downloads at your archive. Without this variable, publishing continues through GitHub Releases.

No existing versions are imported automatically. To publish a prepared build manually, from the repository root:

```bash
read -rs -p 'Archive token: ' ARCHIVE_TOKEN; echo
export ARCHIVE_TOKEN
node archive/client.mjs \
  --url https://wii-uu-archive.stoppedwumm.net \
  --manifest build/release-feed/version.json \
  --asset dist/WII-UU-2.0.9-beta.123.1.zip \
  --asset CHANGELOG.md
unset ARCHIVE_TOKEN
```

Use the actual ZIP filename generated by `package.sh`. The client streams files, then publishes atomically; incomplete uploads are not listed. Identical retries succeed. Published bytes and metadata cannot be replaced. There is intentionally no remote delete endpoint.

## Public endpoints

| Endpoint | Result |
| --- | --- |
| `/` | Browse the archive |
| `/healthz` | Process health and release count |
| `/version.json` | Latest stable update manifest |
| `/beta/version.json` | Latest beta manifest |
| `/changelog.md`, `/beta/changelog.md` | Notes for the latest channel release |
| `/api/releases?channel=beta&limit=50&offset=0` | Paginated release/asset index; omit channel for both |
| `/releases/2.0.9-beta.123.1/version.json` | Exact release manifest |
| `/releases/VERSION/FILENAME` | Immutable, SHA-256-identified downloads with Range/HEAD/ETag support |

Authenticated publishing uses `Authorization: Bearer TOKEN`: `PUT /api/releases/VERSION/FILENAME`, then `POST /api/releases/VERSION` with a manifest. Only named release assets are accepted. Default upload cap is 2 GiB (`MAX_UPLOAD_BYTES`); Cloudflare Tunnel/plan request limits also apply.

## Update the server

```bash
cd WII-UU
git pull --ff-only
sudo bash archive/install.sh
```

Configuration and archives remain outside the application directory. To rotate the token, edit `ARCHIVE_TOKEN` in `/etc/wiiuu-archive.env`, restart the service, and update the GitHub secret.

## Local development

```bash
cd archive
npm run setup
npm start
```

`.env` contains the local token and is excluded from git. `node --test archive/test/*.test.mjs` runs real HTTP/upload tests from the repository root. Deploy one server process per data directory; it uses atomic files and an in-memory release index rather than clustering.
